### The process overview

1. **Setup project**
- Setup for SCSS
- Created the following files: `_variables.scss`, `_mixins.scss`, `_bits.scss`  
- Created main `style.scss` to import all partials

2. **Implement Sass features**
 - **Variables:** `$base-font` and colors for subnet classes  
   - **Mixins:** `big-text()` for consistent font styling; `bit-box()` for reusable color/background/font-weight styles  
   - **Nesting:** Grouped child selectors under `#ipv4` for clarity and maintainability  
   - **Extend/Inheritance:** `%bit-style` extended by `.subnet_class_bits`, `.subnet_bits`, and `.host_bits`  

3. **Compilation & Testing**
